# Contributing to the Internships and new-grad jobs list

Help students and recent graduates find roles with clear eligibility rules. Please include the employer's posting so readers can check who can apply.

## What belongs in this list

Internships, student programs, and roles intended for new or recent graduates belong here.

## Suggest a job

Include the exact role title, employer's own apply link, and any stated graduation or student eligibility.

[Open the Add a job form](https://github.com/Jobhacki/internships-new-grad-2027/issues/new?template=add-a-job.yml)

## Report a dead link

Include the internship or graduate role title, employer, link, and the status shown on the page.

[Open the Report a dead link form](https://github.com/Jobhacki/internships-new-grad-2027/issues/new?template=report-a-dead-link.yml)

## Ground rules

- Use the issue forms above. The table in the README is generated, so a pull request that edits it will be overwritten on the next refresh.
- Links must go to the employer's own career page or hiring system. Links to job aggregators and links with tracking or session parameters are not added.
- Please do not include personal data about anyone.
- We review suggestions by hand and cannot promise a timeline or that every suggestion is added. The employer's page is always the source of truth for a listing.
